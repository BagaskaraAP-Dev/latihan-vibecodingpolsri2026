# Changelog — IT-Festival 2026 POLSRI

Semua perubahan penting pada proyek ini dicatat dalam berkas ini.

## [1.2.0] - 2026-09-20
### Ditambahkan
- **Fitur Backup JSON:** Tombol ekspor data peserta ke format JSON langsung dari User Dashboard.
- **Shortcut Keyboard:** Penutupan modal autentikasi secara instan menggunakan tombol `Escape`.
- **Aset Vektor Maskot Belibit:** Penambahan pose idle, cyber coder, champion, dan retro gamer dalam format SVG mandiri di direktori `assets/`.
- **Favicon Retro:** Ikan Belida cyberpunk pixel art berukuran 64x64 pada tab peramban.
- **Automated Test Suite (`test/verify-storage.js`):** Pengujian otomatis 23 poin mencakup integritas routing, data alamat, kontak, dan aset.
- **Continuous Integration (CI):** Integrasi workflow GitHub Actions untuk memvalidasi build setiap commit.
- **Lisensi MIT:** Hak cipta resmi atas nama Bagaskara Amukti Palapa.
